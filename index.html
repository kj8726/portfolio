Chose the `mssql` npm package over an ORM deliberately — to be able to speak fluently about transactions, isolation, and stored procedures in interviews instead of abstracting them away.

CREATE PROCEDURE sp_PlaceOrder -- wraps stock check + order insert + stock decrement AS BEGIN SET XACT_ABORT ON; BEGIN TRY BEGIN TRANSACTION; -- validate stock, insert order, update inventory COMMIT TRANSACTION; END TRY BEGIN CATCH ROLLBACK TRANSACTION; THROW; END CATCH END
